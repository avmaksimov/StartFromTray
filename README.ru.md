# StartFromTray

[English](README.md) | **Русский**

StartFromTray — портативная программа для быстрого запуска приложений, документов, папок и скриптов из системного трея Windows.

Часто используемые команды размещаются в настраиваемом многоуровневом меню. Для каждого элемента доступны три действия: запуск, редактирование целевого файла и быстрый переход к настройкам элемента.

## Управление мышью

| Кнопка мыши | Действие                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------ |
| Левая       | Запустить или открыть выбранный элемент                                                          |
| Правая      | Открыть целевой файл в настроенном редакторе или выполнить системное действие Windows «Изменить» |
| Средняя     | Открыть выбранный элемент в окне настройки StartFromTray                                         |

Это особенно удобно для скриптов: левой кнопкой можно выполнить скрипт, а правой — сразу открыть его в редакторе.

## Возможности

* Создание многоуровневого меню команд с вложенными группами.
* Запуск приложений, документов, папок, скриптов и других объектов, поддерживаемых оболочкой Windows.
* Указание отдельных параметров командной строки для каждого элемента.
* Запуск команд и редакторов с правами администратора.
* Копирование, переименование, перемещение и изменение порядка элементов в дереве.
* Немедленное применение изменений или отмена всех несохранённых изменений.
* Автоматическое назначение иконок или их выбор из файлов `.exe`, `.dll` и `.ico`.
* Назначение элементу иконки выбранного расширения файла.
* Автоматический запуск StartFromTray при входе в Windows.
* Отображение состояния запущенного из меню процесса.
* Защита от повторного запуска одного элемента, пока запущенный им процесс продолжает работать.
* Отметка команд, для которых не удалось найти целевой файл.
* Поиск исполняемых файлов через записи `App Paths` в реестре Windows и переменную окружения `PATH`.

## Настраиваемые действия запуска и редактирования

StartFromTray позволяет назначить отдельные приложения для **запуска** и **редактирования** файлов с выбранными расширениями.

Например, можно:

* выполнять файлы `.ps1` с помощью PowerShell, а редактировать их в Visual Studio Code;
* запускать скрипты с дополнительными параметрами;
* использовать разные редакторы для разных типов файлов;
* добавлять собственные фильтры типов файлов в окно выбора команды.

Для приложений запуска и редактирования можно задать отдельные параметры командной строки. Подстановка `:(command)` позволяет явно указать место выбранного файла в строке параметров.

Если собственное действие редактирования не настроено, StartFromTray использует файловую ассоциацию Windows. Если редактор для файла не зарегистрирован, программа открывает Проводник и выделяет этот файл.

## Портативная работа

StartFromTray не требует установки. Меню команд, правила для расширений, языковые файлы и настройки программы хранятся рядом с исполняемым файлом.

Программу следует размещать в папке, доступной текущему пользователю Windows для записи. После этого всю папку можно переносить или сохранять в качестве резервной копии.

## Поддержка языков

Интерфейс поддерживает внешние языковые файлы, расположенные в каталоге `Langs`. Новые переводы можно добавлять без перекомпиляции программы.

StartFromTray — нативное Windows-приложение, написанное на Delphi с использованием VCL.
