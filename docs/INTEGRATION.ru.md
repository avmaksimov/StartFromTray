# Настройка оснасток MMC

Локальные оснастки, установленные в Windows, появляются в списке автоматически.
Для обычного локального запуска ничего настраивать не требуется.

Файл `mmc-remote.ini` рядом с `StartFromTray.exe` определяет, какие оснастки
можно также открыть для удалённого компьютера.

## Локальный или удалённый компьютер

- **Локальный** — оснастка запускается без дополнительных параметров.
- **Удалённый** — выберите или введите имя компьютера. Этот вариант доступен
  только для оснасток, перечисленных в `mmc-remote.ini`.

Формат файла:

```ini
[Remote]
services.msc=/computer:{computername}
eventvwr.msc=/computer:{computername}
```

`{computername}` заменяется выбранным именем компьютера. Для добавления другой
оснастки укажите имя её `.msc`-файла и поддерживаемый ею параметр запуска.

## Последние компьютеры

StartFromTray запоминает недавно использованные имена и предлагает их при
вводе. Настройки хранятся в `StartFromTray.ini`:

```ini
[MMC]
MaxRecentComputers=10
RecentComputers=SERVER1;SERVER2
```

`MaxRecentComputers` задаёт максимальное количество имён. Если параметр не
указан, сохраняется до 10 компьютеров. Значение `0` отключает историю.

## Права администратора

Выбор MMC не меняет настройку **«Запускать от имени администратора»**.
Включайте её вручную, если выбранное действие требует повышенных прав.
Для удалённого управления также необходимы соответствующие права на целевом
компьютере и разрешённый сетевой доступ к его службам управления.
