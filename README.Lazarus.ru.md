# StartFromTray для Lazarus 4.8

Это перенос исходного проекта Delphi/VCL на Lazarus 4.8 и FPC 3.2.2.
Основная цель текущей версии — Windows (Win32/Win64, widgetset Win32/Win64).

## Как открыть и собрать

1. Откройте в Lazarus файл `StartFromTray.lpi`.
2. Выберите целевую архитектуру Windows в параметрах проекта.
3. Выполните **Запуск → Очистить и собрать**.

Открывать `StartFromTray.lpr` как отдельный файл не нужно: это главный исходник,
но параметры проекта, список модулей и зависимость от LCL находятся в `.lpi`.

Исполняемый файл должен находиться рядом с `Items.xml`, `Filters.ini`,
`StartFromTray.ini` и папкой `Langs`. Значок приложения уже включён в
`StartFromTray.res`.

## Управление мышью

На значке в системном трее:

- левая кнопка открывает меню команд;
- средняя кнопка открывает окно настроек;
- правая кнопка открывает служебное меню «Настройки / Выход».

На конечном пункте меню команд:

- левая кнопка запускает команду;
- средняя кнопка открывает соответствующий элемент в настройках;
- правая кнопка выполняет действие редактирования.

При включённой в Windows перестановке основной и дополнительной кнопок действия
запуска и редактирования меняются местами, как в исходной версии.

Трёхкнопочная обработка реализована поверх штатного `TPopupMenu`. Иконки,
вложенные меню, состояния пунктов и клавиатурная навигация остаются системными.

## Совместимость данных

`Items.xml` сохраняет прежнюю структуру и имена атрибутов:

- корень `tree2xml` с `name="tvItems"`;
- вложенные элементы `item`;
- `Caption`, `isGroup`, `Command`, `CommandParameters`, `IsRunAsAdmin`,
  `IconType`, `IconFilename`, `IconFileIndex`, `IconExt`;
- свойства со значениями по умолчанию по-прежнему не записываются.

Файл записывается в UTF-8 без BOM и без XML-декларации, с отступом в два
пробела и CRLF — как файл исходного проекта. Перед первым запуском всё же
рекомендуется сохранить резервную копию рабочего `Items.xml`.

RTTI продолжает использоваться для чтения/записи данных и переводов. Обработаны
все строковые типы FPC (`AnsiString`, `WideString`, `UnicodeString`) и отдельный
тип RTTI `tkBool`, которого не было в проверках исходной Delphi-версии.

## Linux

Формы и большая часть логики уже используют LCL, но эта ветка проекта пока
целенаправленно собирается для Windows. Для нативной Linux-сборки нужно заменить
WinAPI-части: системные ассоциации и значки, реестр автозапуска,
`ShellExecuteEx`, выбор ресурса иконки и перехват событий нативного меню GTK/Qt.
Формат XML, RTTI-модель и формы при этом менять не потребуется.
